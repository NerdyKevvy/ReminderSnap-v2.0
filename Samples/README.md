# Fictional import fixtures

These tiny fixtures were generated for OCR tests. They are not real coursework.

- `Cropped-homework.png`: image reading, including a very short crop.
- `Example-homework.pdf`: the same assignment with selectable text; should skip OCR.

They show Homework 5 due September 24, 2026 at 23:59 EDT. The date is intentionally fixed for repeatable tests. There is no course in the crop: enter `CS-UY 1134` in **Import → Working with a crop?** before importing, or correct it in the task editor afterward. Do not save these fixtures into a real coursework list unless you intentionally want a test task.

For a safer walkthrough, use the app's built-in **Explore the sample** instead: its dates are relative to today and its **Test save** cannot write to Apple’s apps.
