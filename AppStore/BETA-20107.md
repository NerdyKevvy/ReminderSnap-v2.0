# ReminderSnap 2.1 (20107) — internal testing

## Changes

- Courses can be added, renamed, archived or removed in Settings. Rename updates
  saved assignments without replacing their task or external-link IDs. Removing
  preferences keeps saved assignments, reminders and calendar blocks.
- Section codes are explicitly labelled. Calendar colours use named swatches,
  replacing numbered choices. Archived profiles do not supply import defaults.
- Import context resets for new batches. Images without course evidence never
  inherit a course from another image. Fix details supports per-image correction.
- Table parsing uses column roles and a shared baseline slope. A final semantic
  gate rejects scores/status/header text from every parser and the save path.
- Local OCR adds bounded screen geometry correction, a title-column retry and
  spatial deduplication. Uncertain OCR/ambiguous identifiers are not preselected.

Recognition remains local. No hosted AI service, paid inference or screenshot
uploads were added. Existing public App Store versions are unchanged.

## What to test — English

1. Import a Gradescope/Canvas screenshot or a clear laptop-screen photo. Verify
   complete assignment names and due dates; scores/status labels must not be tasks.
2. In Fix details, correct the course for one image. Import an unrelated image
   without a course title: it must remain uncategorized until you choose.
3. Settings → Courses & sections: edit a name, section and colour. Archive a
   finished course. Delete preferences and confirm saved assignments remain.
4. Rename a course containing linked tasks; check that the original linked
   entries update without duplicates after the correct account/device reconnects.

## 测试重点 — 简体中文

1. 导入 Gradescope、Canvas 截图或清晰的电脑屏幕照片，核对完整作业名称与截止时间。
   分数、提交状态、表头不应成为任务。
2. 在“补全信息”中逐张修正课程。再导入不含课程名的其他图片，不应沿用上次课程。
3. 设置 → 课程与班级：修改课程名、班级代码和颜色；归档已结束课程；删除课程偏好后，
   已保存作业仍应保留。
4. 重命名含有关联任务的课程后，在正确账户／原导出设备连接时检查原有关联条目更新，
   不应重复创建。

## Verification and limits

- Parser/date/notification/permission regressions and twelve generated variations
  of slanted/reordered table geometry passed.
- Actual local OCR passed generated irregular, rotated and perspective-distorted
  tables: four correct names/courses/deadlines each, no score/status tasks. Cropped
  PNG, Photos-style image data, embedded PDF and five warm rereads also passed.
- Isolated Core Data tests covered renaming, preserved external IDs, unaffected
  unrelated assignments, archiving, deletion markers and reopening the database.
- Mac course editor was visually inspected in an isolated, sandboxed app with
  cloud sync disabled. No personal assignments or external calendar data changed.
- The original October 25 source screenshot was not available to the test runner;
  the reported output and generalized generated variations informed the checks.
  These tests are regression coverage, not a measured real-world accuracy rate.
- Real camera glare/blur, cross-device iCloud conflict resolution and every new
  course layout still require device acceptance. Very unclear text can require
  confirmation; OCR does not invent a hidden course, section or year.
